# Erica Resendez — Responsive Portfolio

## Files
- `index.html` — Home page
- `projects.html` — Projects/Work page
- `about.html` — About/Contact page
- `style.css` — Shared responsive stylesheet
- `wireframe.png` — Three-page layout planning sketch

## Design choices
- Colors: navy blue, medium blue, pale blue, and white.
- Google Fonts: Poppins for headings and Open Sans for body text.
- Spacing: an 8px-based scale (8, 16, 24, 32, 48, 64px).
- Layout: CSS Grid and Flexbox.
- Responsive breakpoints: 768px (tablet) and 1200px (desktop).

## Test at the required widths
Open the site in Chrome, press `F12` (or right-click → Inspect), then click the device toolbar icon. Enter these widths:
1. 320px — mobile
2. 768px — tablet
3. 1200px — desktop

At each width, check that the navigation fits, text is readable, cards stack or form columns appropriately, and there is no horizontal scrolling.

## Publish with GitHub Pages
1. Upload all files in this folder to the root of your GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish. The live URL will appear in the Pages section.

The Google Fonts stylesheet requires an internet connection. The site still has fallback sans-serif fonts if Google Fonts cannot load.
